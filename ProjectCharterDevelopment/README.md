# Stage 2 Report – Project Charter Development

## 1. Project Objectives

**Purpose:** The **Jirah (Local Helpers)** project aims to facilitate obtaining daily assistance for individuals by connecting them with their nearby neighbors, enhancing the spirit of cooperation and social support in the local community.

**Objectives (SMART):**

1. Develop a Minimum Viable Product (MVP) for the application within **8 weeks** that includes: user registration, creating help requests, and a simple location-based matching system.

2. Enable users to communicate through secure internal chat, aiming to ensure a response rate of no less than 80% of requests within a specified period from posting.

3. Create a rating and review system to build trust between users, achieving a satisfaction rate of no less than **90% within the first three months** of trial usage.

## 3. Project Scope

### In-Scope (MVP Deliverables)
- User account registration (sign up/login)
- Publishing help requests with details (task type, time, location)
- Basic matching system based on geographical proximity
- Secure internal chat between help requester and provider before agreement
- Rating and review system to build trust between users

### Out-of-Scope (Excluded from MVP)
- National expansion across all cities of the Kingdom in the first phase (initially focusing on a limited scope)
- Integration with **Nafath platform** to ensure identity verification and security
- Integration with charitable organizations or government agencies (possible in the future)
- Mobile application with multi-language support

## 4. Risks

| Risk | Description | Mitigation Plan |
|------|-------------|-----------------|
| **User Safety** | Potential platform exploitation or presence of untrustworthy users | Account verification, rating system, reporting capability |
| **Poor Internet Connectivity in Some Areas** | Some users may not be able to use the application | Provide a Lite version or limited offline mode support |
| **Low User Engagement** | Users may hesitate to request or provide help | Awareness campaigns, add incentives like points/badges for participants |
| **Time Pressure on Team** | Potential development delays | Divide tasks weekly and use project management tools (Trello) |
